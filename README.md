# Spotify-Analysis-Dashboard-Power Bi
Project Overview – Spotify Data Analysis (Power BI)
An interactive Power BI dashboard built to analyze Spotify music data and uncover listening trends.
Focuses on song popularity, artists performance, and track characteristics using visual analytics.

📊 Key Insights Covered

Analysis of Top Songs and Artists based on popularity scores.
Trends in song duration, explicit content, and album types.
Popularity comparison across release dates and total tracks.
Identification of most consistent and high-performing artists.
Insights into how song features impact popularity.
🛠 Tools & Technologies Used

Power BI Desktop for data modeling and dashboard creation.
DAX measures for calculated metrics and KPIs.
Data cleaning & transformation using Power Query.
Interactive visuals like cards, bar charts, line charts, and slicers.

📈 Dashboard Features

Fully interactive filters for artists, songs, and albums.
Clean and user-friendly visual storytelling layout.
KPI cards highlighting key performance metrics.
Dynamic visuals for quick comparison and trend analysis.

To demonstrate data analysis, visualization, and business insight generation skills.
